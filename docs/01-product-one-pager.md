# One Move — 一页产品定义（Phase 1）

> **版本**：v0.1（Phase 0 第 1 步基线）
> **状态**：待用户审阅确认

---

## 1. 产品一句话定位

**One Move** 是一个面向 FPL（Fantasy Premier League）玩家的**赛前决策工作台**：每周基于公开球队状态与赛前信息，给出**唯一一个最高优先级行动建议（含“不动”）**，支持玩家用自然语言质疑与追加约束重算，并通过赛后实际得分复盘来校准决策质量。

---

## 2. 我们解决什么问题（痛点）

1. **信息过载、决策瘫痪**：传统 FPL 工具（如 FFHub、FPL Review）提供大量预期得分表格和复杂多轮路线，对普通/轻度玩家门槛过高，看完依然不知道“这周到底先动哪一步”。
2. **规则复杂导致误操作**：免费转会名额（FT）累积、超额 -4 罚分、银行余额与卖出价折算、同队最多 3 人等规则容易算错，玩家常在“不该动的时候乱换人”或“白白扣 4 分”。
3. **缺少“不动”的一等公民地位**：多数推荐工具默认鼓励操作，忽略了保留 FT 的多轮机会价值。
4. **单向输出、无法按个人偏好重算**：传统数学优化器不支持玩家说“我就是想留着某人、下周攒钱买某人，帮我重算”。

---

## 3. 目标用户与典型使用场景（Phase 1）

- **目标用户**：FPL 玩家（Phase 1 优先服务单用户自用与作品集演示场景）。
- **准入方式**：**无需注册登录**，输入任意公开的 FPL `Team ID` 即可使用。
- **核心使用节奏（每周一次闭环）**：
  1. **载入快照**：赛前输入 `Team ID`，系统自动拉取公开球队阵容、银行余额，并基于转会历史推算当前 FT（卖出价标为估算，支持手动微调）。
  2. **获得唯一建议**：工作台用人话展示关键状态（FT、可用预算、是否扣分），给出唯一推荐的 `One Move`（可能是转会、队内换首发/队长，或明确建议**“不动”**）及理由。
  3. **质疑与加约束重算**：用户若不认同或有特定想法，可用自然语言追问或附加约束（如“留着某球员”、“不扣 4 分”、“粘贴一段赛前伤停新闻”），Agent 转译约束后重新计算合法方案。
  4. **HITL 人工确认**：用户自行决定是否采纳，并在 FPL 官网手动执行操作（本产品绝不自动提交）。
  5. **赛后复盘**：本轮比赛结束后，记录实际采纳动作与真实得分，对比 Baseline（如“每周不动”）评估决策效果。

---

## 4. Phase 1 核心边界（做什么 vs 不做什么）

### Phase 1 必须做（In-Scope）
1. **免登录 Team ID 接入**：拉取公开 API 数据，自动推算 FT，明确标注估算卖出价并支持手动校准。
2. **确定性规则与合法性守护**：严格校验预算（ITB + 卖出价）、FT 与 -4 罚分、同队最多 3 人、位置人数限制，拦截所有非法建议。
3. **“不动”作为一等公民与动作粒度定义**：
   - 在收益比较中计入保留 FT 的多轮机会价值，与转会/调阵平等竞争“唯一推荐”。
   - **动作粒度（1 个核心转会决策 + 配套零成本调阵）**：主结论在「1 笔转会（附带最新最优 11 人首发与队长） / 不买人仅调首发与队长 / 完全不动」中三选一；默认只推 1 笔转会，仅当用户通过自然语言追问明确要求（如“同时换 2 人”）时才重算多转会方案并醒目标注是否触发 -4 罚分。
4. **Agent 智能核心**：
   - 解析用户粘贴的非结构化赛前新闻（伤停/轮换风险）；
   - 将自然语言约束转译为确定性重规划参数，参数校验失败时可自我修正；
   - 基于程序计算结果组织清晰、诚实的人话解释。
5. **决策工作台形态**：球队状态可视化 + 唯一建议卡片 + 按需追问重算 + 决策采纳与赛后复盘记录（非纯聊天框）。
6. **双轨评测基线**：支持基于历史快照的离线回放评测（Offline Replay）与每周赛后在线复盘（Online Outcome）。

### Phase 1 明确不做（Non-Goals）
- **绝不自动向 FPL 官方提交阵容或转会**（严守 HITL 边界）。
- **不做账号体系、登录注册与多租户权限隔离**。
- **不做官方账号/Cookie 绑定或浏览器插件抓真实买入价**（先用“估算卖出价 + 手动微调”）。
- **不做 Wildcard / Free Hit / Bench Boost / Triple Captain 等芯片的跨多周联合规划**。
- **不做全网实时新闻/社媒自动爬虫**（Phase 1 先支持粘贴新闻文本 + 样例输入）。
- **不强行引入 RAG、多智能体（Multi-Agent）或 MCP**。

---

## 5. Phase 1 成功标准（怎么算做成）

1. **端到端闭环可演示**：任意有效 `Team ID`（及离线固定样例）可完整走通 `载入快照 → 给出含“不动”的唯一建议 → 加约束重算 → 确认记录 → 赛后计分复盘`。
2. **零规则幻觉**：任何推荐方案 100% 满足 FPL 预算、人数与同队上限约束；模型解释中的数字与程序计算结果完全一致。
3. **可评测**：建立首批离线回放评测集，能够量化统计结构化输出合法率、约束遵守率与“不动”决策合理性。
